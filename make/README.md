# make/

Tools for building your own mods and sharing them as packs. Start with
[../docs/MAKING_MODS.md](../docs/MAKING_MODS.md).

| | |
|---|---|
| `extract_resources.py` | every picture and sound in your backup, as files |
| `make_pack.py` | stock backup + your modded image -> a pack (no firmware inside) |
| `sounds/` | fit any WAV to a sound slot; build the sound image; the Receipt Quest sounds |
| `screens/` | the Receipt Quest menus, screens and photo frames, and their builders |
| `effect/` | the in-camera print effect: C source, loader stub, build, emulator tests |
| `pc-converter/` | no flashing: turn the photos on the SD card into pixel-art prints on a PC |
